# Contract: predict_enhanced.py (CLI 入口點)

**Module**: `src/cli/predict_enhanced.py`
**Version**: 1.0.0
**Status**: Stable

## CLI 介面規格

### 指令名稱

```bash
python src/cli/predict_enhanced.py
```

### 命令列參數

| 參數 | 縮寫 | 必填 | 型別 | 預設值 | 說明 |
|------|------|------|------|--------|------|
| `--model-file` | `-m` | 是 | str | - | 訓練好的模型檔案路徑 (.h5) |
| `--data-file` | `-d` | 是 | str | - | 歷史資料 CSV 檔案路徑 |
| `--input-date` | `-i` | 是 | str+ | - | 輸入日期 (可指定多個) |
| `--output-dir` | `-o` | 否 | str | "outputs" | 視覺化圖片輸出目錄 |
| `--feature-set` | `-f` | 否 | str | "Set A" | 特徵集 ID (Set A/B/C) |
| `--time-steps` | `-t` | 否 | int | 60 | 時間窗口大小 (20/40/60/80) |
| `--no-plot` | - | 否 | flag | False | 僅輸出文字結果,不生成圖片 |
| `--verbose` | `-v` | 否 | flag | False | 顯示詳細日誌 |

### 執行範例

```bash
# 基本用法: 預測單一日期
python src/cli/predict_enhanced.py \
    --model-file models/best_tuned_model_20251116_153022.h5 \
    --data-file 19980601-20251111-converted.csv \
    --input-date "2024-01-15"

# 批次預測多個日期
python src/cli/predict_enhanced.py \
    --model-file models/best_tuned_model_20251116_153022.h5 \
    --data-file 19980601-20251111-converted.csv \
    --input-date "2024-01-15" "2024-02-20" "2024-03-10" \
    --output-dir results

# 僅文字輸出 (不生成圖片)
python src/cli/predict_enhanced.py \
    -m models/best_tuned_model_20251116_153022.h5 \
    -d 19980601-20251111-converted.csv \
    -i "2024-01-15" \
    --no-plot
```

### 錯誤處理

| 錯誤情境 | 退出碼 | 錯誤訊息範例 |
|---------|-------|-------------|
| 模型檔案不存在 | 1 | "錯誤: 找不到模型檔案 models/xxx.h5" |
| 資料檔案不存在 | 1 | "錯誤: 找不到資料檔案 data.csv" |
| 日期格式錯誤 | 1 | "錯誤: 日期格式不正確 '2024/1/1',請使用 YYYY-MM-DD" |
| 日期不在資料範圍 | 1 | "錯誤: 輸入日期 2024-01-15 不在歷史資料範圍內" |
| 資料不足 (< time_steps) | 1 | "錯誤: 輸入日期前的資料點不足 60 天" |
| 輸出目錄無法建立 | 1 | "錯誤: 無法建立輸出目錄 /invalid/path" |

### 退出碼規範

| 退出碼 | 意義 |
|-------|------|
| 0 | 成功 (所有預測完成) |
| 1 | 參數錯誤或輸入驗證失敗 |
| 2 | 模型載入失敗 |
| 3 | 資料載入失敗 |
| 4 | 預測執行失敗 |
| 5 | 視覺化生成失敗 |

### 效能承諾

- 單次預測執行時間: < 5 秒 (包含視覺化)
- 批次預測 (10個日期): < 50 秒
- 記憶體使用: < 2 GB (載入模型 + 資料 + 視覺化)

### 相容性

- Python 版本: 3.12.3 (使用者指定)
- 作業系統: Windows (透過 WSL2 Ubuntu) 或 Linux
- 終端機: 支援 UTF-8 中文顯示

### 簽名

    """
    CLI 主程式入口點

    Returns:

        6. 回傳退出碼
    """
